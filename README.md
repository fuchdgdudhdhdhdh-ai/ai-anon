# Алексей Нейросеть — ИИ-персонаж в Telegram

Открыто представленный как нейросеть аккаунт-персонаж, отвечающий в чате в
твоём стиле общения (Groq / Llama 3.3 70B — бесплатно и быстро).

## Структура проекта

```
local_settings.py      ← ЕДИНСТВЕННЫЙ файл, который стоит править руками
config.py               читает секреты из переменных окружения (.env / Render)
storage.py               хранение настроек (телефон, чат, стиль, триггеры)
telethon_manager.py      вход в аккаунт-персонаж, работа с чатом (Telethon)
ai_client.py              обращение к Groq
userbot_runtime.py        слушает чат, проверяет триггеры, зовёт нейросеть
bot.py                    бот-помощник (aiogram): вход, кнопки, триггеры
web_server.py              health-check для Render + автобудилки
main.py                    точка входа
render.yaml                 описание сервисов для Render (веб + cron)
```

**Всё, что можно захотеть подкрутить без разбора остального кода — имя
персонажа, системный промпт, параметры генерации, лимиты — лежит в
`local_settings.py`.** Остальные файлы трогать не нужно.

## 1. Что понадобится (секреты)

- **api_id / api_hash** — https://my.telegram.org → «API development tools»
  (вход в сам аккаунт-персонаж)
- **BOT_TOKEN** — создать бота у [@BotFather](https://t.me/BotFather)
  (служебный бот для настройки — не путать с аккаунтом-персонажем)
- **GROQ_API_KEY** — https://console.groq.com/keys (бесплатно, без карты)
- **OWNER_ID** — твой числовой Telegram ID, узнать у [@userinfobot](https://t.me/userinfobot)

Все эти значения — секреты. Они НЕ хранятся в коде и не идут в GitHub
(см. `.gitignore`), только в `.env` локально или в переменных окружения Render.

## 2. Заливка на GitHub

```bash
cd telegram_ai_persona
git init
git add .
git commit -m "Init"
git branch -M main
git remote add origin https://github.com/<твой_логин>/<репозиторий>.git
git push -u origin main
```

`.env`, файл сессии (`*.session`) и `data/*.json` в репозиторий не попадут —
это исключено в `.gitignore`, секреты туда класть не нужно.

## 3. Деплой на Render

1. На https://dashboard.render.com → **New → Blueprint** → выбери свой
   GitHub-репозиторий. Render сам прочитает `render.yaml` и создаст два
   сервиса: `ai-persona-bot` (веб) и `ai-persona-keepalive` (крон).
2. У сервиса **ai-persona-bot** в разделе Environment впиши секреты:
   `BOT_TOKEN`, `API_ID`, `API_HASH`, `GROQ_API_KEY`, `OWNER_ID`.
3. Дождись первого деплоя, скопируй URL сервиса (вида
   `https://ai-persona-bot-xxxx.onrender.com`).
4. У сервиса **ai-persona-keepalive** впиши переменную `PING_URL` = этот URL
   (без `/health` на конце — он уже добавлен в команде крона).
5. Готово. Открой своего бота-помощника в Telegram и нажми `/start`.

### Про автобудилку

Бесплатный веб-сервис Render засыпает примерно после 15 минут без запросов.
Cron job каждые 10 минут дёргает `PING_URL/health` и не даёт сервису уснуть —
поэтому и сессия Telethon, и сохранённые настройки (файл `persona_session.session`
и `data/storage.json`) остаются на диске между пингами. Учти: при **новом
деплое** (git push) диск пересоздаётся заново, и `/relogin` придётся сделать
повторно — это ожидаемо и отражает исходное требование «если сессия слетела —
переспросить вход». Если хочешь, чтобы сессия переживала и сами деплои —
в Render это делается платным Persistent Disk, дай знать, добавлю его в
`render.yaml`.

## 4. Первая настройка (в боте-помощнике)

1. `/start` → отправь номер телефона (текстом или кнопкой).
2. Введи код из Telegram цифровой клавиатурой прямо в чате с ботом.
3. Если включена двухфакторка — пришли пароль сообщением (бот сразу
   удалит его из чата).
4. Пришли ссылку/username/ID чата, где персонаж будет общаться.
5. Разреши автосбор примеров твоего стиля из истории чата (или добавь
   позже `/style`).

## 5. Управление триггерами и ссылками — прямо в боте

Команда `/triggers` открывает список кнопками:

- **➕ Добавить триггер** → бот спросит фразу → тип (📝 текст / 🔗 ссылка) →
  содержимое. Всё вводится сообщениями, никакого специального синтаксиса.
- Тап по существующему триггеру открывает его: можно **изменить фразу**,
  **изменить ответ/ссылку** или **удалить** (с подтверждением) — всё кнопками.
- Ссылки собеседникам пересылаются тем же механизмом: как только в сообщении
  встретится фраза-триггер (например «резюме» или «портфолио»), персонаж
  сразу отправит привязанную к ней ссылку вместо ответа нейросети.

## 6. Остальные команды бота-помощника

- `/status` — авторизован ли аккаунт, какой чат, сколько примеров стиля и триггеров
- `/relogin` — повторный вход (бот сам пришлёт уведомление, если сессия слетит)
- `/setchat` — сменить чат
- `/style` — обновить примеры стиля из истории чата

## 7. Важно

- Держи переменные окружения Render в секрете — это полный доступ к аккаунту.
- Не спамь чужие чаты и не рассылай сообщения без запроса — чрезмерная
  автоматизация личных аккаунтов не приветствуется правилами Telegram.
- Нейросеть может ошибаться или выдумывать детали — она предупреждена в
  системном промпте (`local_settings.py`) не придумывать факты о твоей жизни,
  но полностью гарантировать это невозможно.
